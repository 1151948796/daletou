# 彩票分析预测器

大乐透 + 双色球 + 排列五 三合一分析预测工具，PWA 手机应用。

## 功能

### 大乐透（前区5个01-35 + 后区2个01-12）
- 频率统计、冷热号、遗漏值、奇偶比、大小比、连号统计
- 5种预测策略

### 双色球（红球6个01-33 + 蓝球1个01-16）
- 红球/蓝球频率统计、冷热号、遗漏值、奇偶比、大小比、连号统计
- 5种预测策略

### 排列五（5个位置各0-9）
- 各位置频率统计、冷热号、遗漏值、奇偶比、大小比、跨度
- 5种预测策略

## 数据来源
- 大乐透/双色球：500彩票网（500期）
- 排列五：huiniao API（300期）

## 本地运行
直接用浏览器打开 `index.html` 即可。

## 部署到 GitHub Pages
1. 将本仓库推送到 GitHub
2. Settings → Pages → Source: Deploy from branch → master / root
3. 访问 https://用户名.github.io/仓库名/

## 声明
彩票开奖是完全随机事件，本程序仅供统计分析学习之用，不构成投注建议。
