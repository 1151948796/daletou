# 大乐透分析预测器

基于 500 期历史数据的统计分析工具，PWA 手机应用。

## 功能
- 📊 频率统计（前区01-35 + 后区01-12）
- 🔥 冷热号分析
- ⏱️ 遗漏值排行
- 🎯 5种策略预测号码
- 📋 历史开奖查询

## 本地运行
直接用浏览器打开 `index.html` 即可。

## 部署到 Gitee Pages
1. 将本仓库推送到 Gitee
2. 进入仓库 → 服务 → Gitee Pages
3. 部署分支选 master，目录选根目录
4. 启动即可获得在线访问地址

## 声明
彩票开奖是完全随机事件，本程序仅供统计分析学习之用，不构成投注建议。
